# 大核协议转换层起步说明

## 1. 第一阶段目标

先跑通最小链路：

```text
以太网 UDP 简单二进制帧
  ↓
ethernet_udp_parse_frame
  ↓
protocol_parsed_msg_t
  ↓
frame_packer_pack
  ↓
unified_frame_t
  ↓
ipc_to_rtos_send stub
```

共享内存发送由队友接入，当前 `ipc_to_rtos_send()` 只打印统一帧内容，后续替换函数内部实现即可。

## 2. UDP 简单二进制帧格式

所有多字节字段均为 little-endian，固定长度 76 字节。

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 2 | magic | 固定 `0x55AA` |
| 2 | 1 | version | 固定 `0x01` |
| 3 | 1 | vehicle_type | 车身业务类型，例如 `0x49` 灯光控制 |
| 4 | 1 | can_flags | `unified_can_flag_t` bitmask |
| 5 | 1 | can_dlc | 普通 CAN 为 `0~8`，CAN FD 为 `0~64` |
| 6 | 4 | can_id | CAN 标准 ID 或扩展 ID |
| 10 | 64 | can_data | CAN/CAN FD 数据区，不足补 0 |
| 74 | 2 | crc16 | CRC-16/CCITT-FALSE，覆盖前 74 字节 |

解析成功后固定填入：

```text
source_protocol = PROTOCOL_TYPE_ETHERNET
source_id = 0
destination_id = 0
```

## 3. 构建和测试

构建大核应用：

```bash
./scripts/build_linux_app.sh
```

运行单元测试：

```bash
./scripts/test_linux_app.sh
```

运行 UDP 接收端：

```bash
./build/linux_app/linux_app --udp-port 5000
```

发送一帧测试数据：

```bash
./tools/send_udp_frame.py 127.0.0.1 --port 5000 --vehicle light --can-id 0x123 --data 0102030405060708
```
