# Web 演示模式计划

## 摘要

为 `web/` 模块新增 `put-webd --demo-mode` 启动参数，进入固定的 `ethernet_to_can` 演示场景。演示模式保持 Web 后端只读，不控制真实设备，不向小核或物理接口发送命令，只在现有 REST API 返回前叠加演示数据。

演示目标是让现场页面稳定展示 Ethernet 输入、解包为 anyMSG、写入 IPC、路由到 CAN、CAN 封包发送的完整链路；同时强制显示 CAN、Ethernet、Wi-Fi、Bluetooth、RS485 成功接入，4G 未接入。

## 接口与行为

- 启动命令：`put-webd --config web/config/web_config.dev.toml --demo-mode`。
- `/api/health` 保持原字段，并新增 `mode: "normal" | "demo"` 与 `demo_scenario: "ethernet_to_can" | null`。
- `/api/modules` 在演示模式下返回六类接口固定列表，其中 `can`、`ethernet`、`wifi`、`bluetooth`、`rs485` 为 `online`，`4g` 为 `offline`，顶层 `state = "ok"`；`last_rx_ms` 与 `last_tx_ms` 使用真实状态快照值。
- `/api/resources` 保留真实 CPU、内存、磁盘和运行时间；覆盖网络与设备节点，使 Ethernet 为 `up`，CAN/Ethernet/Wi-Fi/Bluetooth/RS485 为 `present`，4G 为 `missing`。
- `/api/ipc-status` 展示 Ethernet RX Ring、CAN TX Ring、Frame Pool、Mailbox、Pending Bitmap 正常，descriptor CRC、epoch、cache sync 错误均为 0。
- `/api/route-status` 展示 route table 正常、`routed_frames` 随时间小幅变化、所有 drop reason 为 0、端到端延迟为低毫秒级。
- `/api/events` 覆盖真实异常事件，只返回演示链路的成功事件。
- `/api/logs` 在演示模式下读取配置 `log_dir` 中的真实日志文件，并复用现有 source 白名单、level/keyword 过滤和 cursor/limit 分页。

## 实现步骤

1. 后端新增启动参数解析结构，保留 `--config/-c`，新增 `--demo-mode`，并在 `AppState` 保存运行模式。
2. 新增 `demo` 辅助模块，集中生成 modules、resources、ipc、route 和 events 的演示覆盖数据。
3. 调整 API handler：普通模式返回真实读取结果；演示模式先读取真实结果，再调用 `demo` 覆盖函数返回稳定演示数据。
4. 日志读取保持真实文件来源，普通模式与演示模式均复用统一过滤和分页逻辑。
5. 前端仅更新 health 类型和顶部状态行，在演示模式显示 `mode demo · ethernet_to_can`。
6. 更新 `web/README.md`，记录演示启动命令和只读边界。

## 验收标准

- `GET /api/health` 返回 `mode = "demo"`、`demo_scenario = "ethernet_to_can"`。
- `GET /api/modules` 显示 5/6 接口在线，且只有 `4g` 为 `offline`。
- `GET /api/modules` 中各接口的 `last_rx_ms` 与 `last_tx_ms` 等于真实 `modules.json` 快照值。
- `GET /api/route-status` 中所有 drop reason 为 0，`state = "ok"`。
- `GET /api/events` 只出现 Ethernet 到 CAN 成功链路事件，无真实 mock 异常污染。
- `GET /api/logs?source=adapter&keyword=...` 从真实 `adapter.log` 读取内容，并正常应用关键字过滤。
- 总览、接口、资源、IPC/路由、事件视图均能稳定展示；日志视图按真实日志文件展示，不注入演示日志。

## 验证命令

```bash
cargo test --manifest-path web/backend/Cargo.toml
npm --prefix web/frontend run build
cargo run --manifest-path web/backend/Cargo.toml -- --config web/config/web_config.dev.toml --demo-mode
```

## 假设

- v1 演示场景固定为 Ethernet 输入、CAN 输出；后续如需多场景，再将 `--demo-mode` 扩展为带值参数或新增场景参数。
- “除 4G 网络外所有接口成功接入”指 PUT 六类物理接口，不包含 USB 设备本身。
- 演示模式是 Web 只读展示覆盖，不替代真实 `linux_app`、共享内存或物理适配器实现。
