
```yaml
# 统一数据帧定义
anyMSG_potocol_structure:
    retries: 1Byte # 重试次数
    __RESERVED__: 1Byte # 保留字段
    __SRCHLD__: 4Byte # 源标记，保留
    destination_cid: 4Byte # 目的通信地址
    source_cid: 4Byte # 源通信地址
    local_time: 4Byte # 本地时间戳
    verify_string[16]: 16Byte # 校验码
    payload_length: 2Byte # 数据帧长度
    type: 1Byte # 数据帧类型
    __PADDING__: 1Byte # 填充字段
    payload: variable # 数据帧负载实体

```

1. `retries` 重试次数
    当前无重试机制，暂定为 1.

2. `__RESERVED__` 保留字段
   保留字段，当前全部填00.

3. `__SRCHLD__` 原标记，保留
   保留字段，当前全部填00.

4. `destination_cid` 目的通信地址
5. `source_cid` 源通信地址

| 地址首字节  | 定义              |
| ----------- | ----------------- |
| 0x00 ~ 0x0F | 保留地址          |
| 0x10 ~ 0x1F | CAN 设备地址段    |
| 0x20 ~ 0x2F | 以太网 设备地址段 |
| 0x30 ~ 0x3F | Wi-Fi 设备地址段  |
| 0x40 ~ 0x4F | 蓝牙 设备地址段   |
| 0x50 ~ 0x5F | 4G蜂窝 设备地址段 |
| 0x60 ~ 0x6F | RS485 设备地址段  |

6. `local_time` 本地时间戳
