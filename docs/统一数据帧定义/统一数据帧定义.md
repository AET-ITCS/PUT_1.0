```yaml
# 统一数据帧定义
anyMSG_potocol_structure:
    msg_length: 2Byte # 帧总字节数
    retries: 1Byte # 重试次数
    __RESERVED__: 1Byte # 保留字段
    __SRCHLD__: 4Byte # 源标记，保留
    destination_cid: 4Byte # 目的通信地址
    source_cid: 4Byte # 源通信地址
    local_time: 4Byte # 本地时间戳
    verify_string[16]: 16Byte # 校验码
    payload_length: 2Byte # 数据帧长度
    type: 1Byte # 数据帧类型
    __PADDING__: 1Byte # 填充字段
    payload: variable # 数据帧负载实体

```


1. `msg_length` 帧总字节数
   包含负载实体与 40Byte 帧头的总字节数

2. `retries` 重试次数
    当前无重试机制，暂定为 1.

3. `__RESERVED__` 保留字段
   保留字段，当前全部填00.

4. `__SRCHLD__` 原标记，保留
   保留字段，当前全部填00.

5. `destination_cid` 目的通信地址
6. `source_cid` 源通信地址

    | 地址首字节  | 定义              |
    | ----------- | ----------------- |
    | 0x00 ~ 0x1F | 保留地址          |
    | 0x20 ~ 0x3F | CAN 设备地址段    |
    | 0x40 ~ 0x5F | 以太网 设备地址段 |
    | 0x60 ~ 0x7F | Wi-Fi 设备地址段  |
    | 0x80 ~ 0x9F | 蓝牙 设备地址段   |
    | 0xA0 ~ 0xBF | 4G蜂窝 设备地址段 |
    | 0xC0 ~ 0xDF | RS485 设备地址段  |
    | 0xE0 ~ 0xFF | 保留              |

7. `local_time` 本地时间戳
   
8. `verify_string[16]` 16字节的校验码
   暂定全部填 00

9. `payload_length` 负载长度
    仅负载实体的字节数

10. `type` 负载类型
    
    | 类型值      | 定义               |
    | ----------- | ------------------ |
    | 0x00        | 端到网关心跳       |
    | 0x01        | 网关到端心跳       |
    | 0x02        | 端到网关健康度     |
    | 0x03        | 网关到端健康度     |
    | 0x04 ~ 0x0A | 网络鉴权           |
    | 0x0D ~ 0x12 | 服务区索引         |
    | 0x15 ~ 0x1E | 网络隧道与端口映射 |
    | 0x1F ~ 0x46 | 保留               |
    | 0x47        | modbusRTU          |
    | 0x48        | modbusTCP          |
    | 0x49        | RAW_CAN            |
    | 0x4A        | CAN_FD             |
    | 0x4B        | CAN_ISOTP          |
    | 0x4C        | UDS                |
    | 0x4D        | J1939              |
    | 0x4E        | CANOPEN            |
    | 0x4F ~ 0xFF | 保留               |

11. `__PADDING__` 填充字段
    填充字段，当前全部填00 

12. `payload` 负载实体
    数据段内容
